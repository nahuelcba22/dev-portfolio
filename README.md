# Portfolio

Personal portfolio of Mariano Nahuel Córdoba: a lofi pixel-art room as a live background
(day/night cinemagraph loops) with the portfolio UI floating on top.

**Stack:** React 19, Vite, Tailwind CSS, Framer Motion, React Router 7.

## Workflow

- `main` is always releasable. No direct commits to `main`.
- One branch per change (`feat/`, `fix/`, `refactor/`, `test/`, `chore/`, `docs/`), merged by PR with **Squash and merge**.
- Commits follow Conventional Commits, written in English.
